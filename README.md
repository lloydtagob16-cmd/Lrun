# LRUN – COMMUNITY WALK/RUN TRACKER

A simple web application that helps community members track, record, and review their walking and running activities.

## 1. Project Information

- **App Name:** LRUN – Community Walk/Run Tracker
- **Community:** Ipil, Zamboanga Sibugay, Philippines
- **Project Type:** Community Web Application
- **Technology:** HTML, CSS, JavaScript, and LocalStorage

## 2. Community Problem

**Who has the problem?**

Community members in Ipil, Zamboanga Sibugay, who enjoy walking, jogging, and running for exercise and fitness.

**How do they handle it today?**

Some people rely on memory or manually record their walking and running activities. This makes it difficult to monitor their progress and maintain consistent activity records.

**Problem Statement:**

In Ipil, Zamboanga Sibugay, community members who enjoy walking and running struggle to keep track of their routes, distance, and activity duration because manually recording activities can be inconvenient and difficult to maintain.

A simple web page where community members can track their walking and running activities, monitor their performance, and save their activity records would help.

## 3. Functional Requirement (FR-01)

**FR-01:**

Users can track and save their walking or running activities, including their GPS route, distance, duration, pace, and activity records using a simple web application with LocalStorage.

## 4. Acceptance Criteria

1. Users can start a walking or running activity and view the available tracking information.
2. The application rejects invalid or inaccurate GPS readings according to its validation rules.
3. Users can pause and resume an activity without losing their current session.
4. Users can finish an activity and save its summary.
5. Saved activity records remain available after refreshing the browser.
6. The application displays an appropriate message when GPS permission is denied or location services are unavailable.

## 5. Main Features

- Walking and running activity tracking
- GPS route monitoring
- Activity timer
- Distance and pace statistics
- Pause and resume controls
- Activity summary
- Saved activities history
- Save activity summary as an image
- LocalStorage data persistence

## 6. Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Geolocation API
- Leaflet Maps
- OpenStreetMap

## 7. Privacy and Data Protection

This project uses made-up demonstration data for academic purposes in accordance with the principles of the Philippine Data Privacy Act of 2012 (RA 10173).

The application does not require a server, user accounts, or an external database. Activity records are stored locally in the user's browser.

## 8. Project Purpose

The purpose of LRUN is to demonstrate how a small and simple web application can help address a community need by providing an accessible way to monitor walking and running activities.

**Developed for:** Lab 1 – Your Own Community Web App
